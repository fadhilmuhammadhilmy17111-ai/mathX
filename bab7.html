Persamaan & Pertidaksamaan

Mempelajari persamaan, pertidaksamaan, nilai mutlak, dan cara menentukan himpunan penyelesaian.

1. Pengertian Persamaan

Persamaan adalah kalimat matematika yang menyatakan bahwa dua bentuk memiliki nilai yang sama.

2x + 4 = 10

Huruf x disebut variabel. Nilai x yang membuat persamaan menjadi benar disebut penyelesaian.

Contoh:

2x + 4 = 10

2x = 10 - 4
2x = 6
x = 3

2. Persamaan Linear Satu Variabel

Persamaan linear satu variabel atau PLSV adalah persamaan yang hanya mempunyai satu variabel dengan pangkat tertinggi 1.

ax + b = 0

dengan a ≠ 0.

Contoh:

5x - 15 = 0

5x = 15
x = 3

3. Persamaan Linear Dua Variabel

Persamaan linear dua variabel memiliki dua variabel, biasanya x dan y.

ax + by = c
Contoh:

2x + y = 8

Persamaan tersebut mempunyai banyak pasangan (x,y) yang memenuhi.

4. Persamaan Kuadrat

Persamaan kuadrat memiliki bentuk umum:

ax² + bx + c = 0

dengan a ≠ 0.

Rumus Kuadrat

x = (-b ± √(b² - 4ac)) / 2a
Contoh:

x² - 5x + 6 = 0

Faktorkan:
(x - 2)(x - 3) = 0

Maka:
x = 2 atau x = 3

5. Pemfaktoran Persamaan Kuadrat

Salah satu cara menyelesaikan persamaan kuadrat adalah dengan faktorisasi.

Contoh:

x² + 7x + 12 = 0

Cari dua bilangan yang jumlahnya 7 dan hasil kalinya 12.

3 dan 4

Jadi:
(x + 3)(x + 4) = 0

x = -3 atau x = -4

6. Diskriminan

Diskriminan digunakan untuk menentukan jenis akar persamaan kuadrat.

D = b² - 4ac
  • D > 0 → dua akar real berbeda.
  • D = 0 → satu akar real kembar.
  • D < 0 → tidak memiliki akar real.
Contoh:

x² - 4x + 4 = 0

D = (-4)² - 4(1)(4)
= 16 - 16
D = 0

Jadi persamaan memiliki akar kembar.

7. Pengertian Pertidaksamaan

Pertidaksamaan adalah kalimat matematika yang menggunakan tanda perbandingan.

<    >    ≤    ≥
Contoh:

x + 3 > 7

x > 7 - 3
x > 4

8. Pertidaksamaan Linear Satu Variabel

Pertidaksamaan linear satu variabel memiliki variabel dengan pangkat tertinggi 1.

Contoh:

3x - 6 ≤ 9

3x ≤ 15
x ≤ 5
Penting: Jika kedua ruas dikalikan atau dibagi dengan bilangan negatif, tanda pertidaksamaan harus dibalik.
Contoh:

-2x > 6

x < -3

9. Pertidaksamaan Kuadrat

Pertidaksamaan kuadrat memiliki bentuk seperti:

ax² + bx + c > 0

atau menggunakan tanda <, ≤, dan ≥.

Contoh:

x² - 5x + 6 > 0

Faktorkan:
(x - 2)(x - 3) > 0

Titik pembatas:
x = 2 dan x = 3

Hasil penyelesaian:
x < 2 atau x > 3

10. Garis Bilangan

Garis bilangan membantu menunjukkan himpunan penyelesaian pertidaksamaan.

  • < atau > menggunakan titik kosong.
  • ≤ atau ≥ menggunakan titik penuh.
Contoh:

x ≥ 3

Artinya semua bilangan yang lebih besar atau sama dengan 3 merupakan penyelesaian.

11. Nilai Mutlak

Nilai mutlak suatu bilangan merupakan jarak bilangan tersebut dari nol pada garis bilangan.

|x| ≥ 0
Contoh:

|5| = 5
|-5| = 5
|0| = 0

12. Persamaan Nilai Mutlak

Untuk persamaan:

|x| = a

jika a ≥ 0, maka:

x = a atau x = -a
Contoh:

|x - 2| = 5

x - 2 = 5
x = 7

atau

x - 2 = -5
x = -3

Jadi:
x = 7 atau x = -3

13. Pertidaksamaan Nilai Mutlak

Untuk a > 0:

|x| < a → -a < x < a
|x| > a → x < -a atau x > a
Contoh:

|x| < 4

Maka:
-4 < x < 4

14. Contoh Soal Campuran

Soal:

Tentukan penyelesaian:
2x + 5 ≥ 13

2x ≥ 8
x ≥ 4
Soal:

Tentukan akar:
x² - 9 = 0

(x - 3)(x + 3) = 0

x = 3 atau x = -3

🧠 Latihan Cepat

Tentukan nilai x dari persamaan:
3x + 6 = 18

📚 Ringkasan Bab 7

  • Persamaan menyatakan dua bentuk matematika memiliki nilai yang sama.
  • PLSV memiliki satu variabel berpangkat satu.
  • Persamaan kuadrat berbentuk ax² + bx + c = 0.
  • Persamaan kuadrat dapat diselesaikan dengan faktorisasi atau rumus kuadrat.
  • Diskriminan: D = b² - 4ac.
  • Pertidaksamaan menggunakan tanda <, >, ≤, atau ≥.
  • Jika dikali atau dibagi bilangan negatif, tanda pertidaksamaan dibalik.
  • Nilai mutlak menyatakan jarak suatu bilangan dari nol.
  • |x| < a berarti -a < x < a.
  • |x| > a berarti x < -a atau x > a.
