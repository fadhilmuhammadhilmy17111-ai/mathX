Vektor

Pelajari konsep vektor, operasi vektor, panjang vektor, dan penerapannya.

1. Pengertian Vektor

Vektor adalah besaran yang mempunyai besar (nilai) dan arah.

Contoh besaran vektor antara lain perpindahan, kecepatan, percepatan, dan gaya.

Notasi Vektor

Vektor dapat ditulis menggunakan huruf dengan tanda panah:

→AB

atau dalam bentuk komponen:

a = (a₁, a₂)

Pada bidang koordinat, komponen pertama menunjukkan arah horizontal dan komponen kedua menunjukkan arah vertikal.

2. Komponen Vektor

Misalkan sebuah vektor memiliki titik awal A(x₁,y₁) dan titik akhir B(x₂,y₂).

Komponen vektor AB dapat dihitung dengan:

→AB = (x₂ − x₁, y₂ − y₁)
Contoh:

A(2,3) dan B(7,6).

→AB = (7 − 2, 6 − 3)
→AB = (5,3)

3. Kesamaan Dua Vektor

Dua vektor dikatakan sama jika mempunyai besar dan arah yang sama.

a = b

Jika:

a = (a₁,a₂)
b = (b₁,b₂)

maka kedua vektor sama jika:

a₁ = b₁ dan a₂ = b₂

4. Penjumlahan Vektor

Penjumlahan vektor dilakukan dengan menjumlahkan komponen yang bersesuaian.

a + b = (a₁+b₁, a₂+b₂)
Contoh:

a = (3,2)
b = (4,5)

a + b = (3+4, 2+5)
a + b = (7,7)

5. Pengurangan Vektor

Pengurangan vektor juga dilakukan berdasarkan komponennya.

a − b = (a₁−b₁, a₂−b₂)
Contoh:

a = (8,6)
b = (3,2)

a − b = (8−3, 6−2)
a − b = (5,4)

6. Perkalian Vektor dengan Skalar

Skalar adalah bilangan yang digunakan untuk mengalikan sebuah vektor.

k(a₁,a₂) = (ka₁,ka₂)
Contoh:

a = (2,4)
k = 3

3a = 3(2,4)
3a = (6,12)
💡 Jika k positif, arah vektor tetap. Jika k negatif, arah vektor berlawanan.

7. Panjang / Magnitudo Vektor

Panjang sebuah vektor menunjukkan besar atau magnitudonya.

Untuk vektor:

a = (a₁,a₂)

panjang vektor adalah:

|a| = √(a₁² + a₂²)
Contoh:

a = (3,4)

|a| = √(3² + 4²)
= √(9 + 16)
= √25
= 5

8. Vektor dalam Tiga Dimensi

Vektor juga dapat ditulis dalam tiga komponen:

a = (a₁,a₂,a₃)

Panjang vektornya adalah:

|a| = √(a₁² + a₂² + a₃²)
Contoh:

a = (2,3,6)

|a| = √(2² + 3² + 6²)
= √(4 + 9 + 36)
= √49
= 7

9. Vektor Satuan

Vektor satuan adalah vektor yang memiliki panjang 1.

Untuk mendapatkan vektor satuan, sebuah vektor dibagi dengan panjangnya.

u = a / |a|
Contoh:

a = (3,4)
|a| = 5

u = (3/5, 4/5)

10. Perkalian Titik (Dot Product)

Perkalian titik digunakan untuk mengalikan dua vektor dan menghasilkan sebuah skalar.

a · b = a₁b₁ + a₂b₂
Contoh:

a = (2,3)
b = (4,5)

a · b = (2×4) + (3×5)
= 8 + 15
= 23

11. Sudut Antara Dua Vektor

Sudut antara dua vektor dapat dicari menggunakan dot product.

a · b = |a||b| cos θ

Sehingga:

cos θ = (a · b) / (|a||b|)
💡 Jika dua vektor tegak lurus, maka hasil dot product-nya adalah 0.

12. Contoh Soal

Soal:

Diketahui:
a = (6,8)

Tentukan panjang vektor a.

Penyelesaian:

|a| = √(6² + 8²)
= √(36 + 64)
= √100
= 10
Soal 2:

Diketahui:
a = (2,5)
b = (3,1)

Tentukan a + b.

Penyelesaian:

a + b = (2+3, 5+1)
= (5,6)

🎯 Latihan Cepat

Diketahui vektor a = (6,8). Berapakah panjang vektor a?

📚 Ringkasan Bab 3

  • Vektor memiliki besar dan arah.
  • Vektor dapat ditulis dalam bentuk komponen.
  • Penjumlahan dilakukan berdasarkan komponen yang bersesuaian.
  • Pengurangan juga dilakukan berdasarkan komponennya.
  • Perkalian skalar mengalikan setiap komponen vektor.
  • Panjang vektor menggunakan rumus Pythagoras.
  • Vektor satuan memiliki panjang 1.
  • Dot product menghasilkan sebuah skalar.
  • Dot product dapat digunakan untuk menentukan sudut antara dua vektor.
