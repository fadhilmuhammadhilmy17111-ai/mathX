BAB 6

Fungsi

Memahami relasi, fungsi, domain, kodomain, range, grafik, serta berbagai bentuk fungsi.

1. Pengertian Fungsi

Fungsi adalah suatu aturan yang memasangkan setiap anggota suatu himpunan dengan tepat satu anggota himpunan lainnya.

Jika himpunan pertama disebut A dan himpunan kedua disebut B, maka fungsi dari A ke B ditulis:

f : A → B

Artinya setiap anggota A memiliki tepat satu pasangan di B.

Contoh:

A = {1, 2, 3}
B = {2, 4, 6}

f(x) = 2x

2. Relasi dan Fungsi

Relasi adalah hubungan antara anggota suatu himpunan dengan anggota himpunan lainnya.

Fungsi adalah relasi khusus yang setiap anggota domainnya mempunyai tepat satu pasangan.

Ingat: Satu input tidak boleh mempunyai dua output berbeda jika hubungan tersebut merupakan fungsi.
Contoh fungsi:
1 → 2
2 → 4
3 → 6
Bukan fungsi:
1 → 2 dan 1 → 5

3. Domain, Kodomain, dan Range

Dalam suatu fungsi terdapat tiga istilah penting:

  • Domain = daerah asal.
  • Kodomain = daerah kawan.
  • Range = hasil atau daerah hasil.
Misalkan:

A = {1, 2, 3}
B = {2, 4, 6, 8}

f(x) = 2x

Domain = {1, 2, 3}
Kodomain = {2, 4, 6, 8}
Range = {2, 4, 6}

4. Notasi Fungsi

Fungsi biasanya ditulis menggunakan notasi:

f(x)

Jika:

f(x) = 3x + 2

maka f(x) merupakan nilai fungsi yang bergantung pada x.

Contoh:

f(x) = 3x + 2

Untuk x = 4:
f(4) = 3(4) + 2
f(4) = 12 + 2
f(4) = 14

5. Menentukan Nilai Fungsi

Untuk menentukan nilai fungsi, kita mengganti x dengan nilai yang diberikan.

f(x) = 2x² - 3x + 1
Contoh: Tentukan f(2).

f(2) = 2(2²) - 3(2) + 1
= 2(4) - 6 + 1
= 8 - 6 + 1
= 3

6. Menentukan Rumus Fungsi

Jika bentuk fungsi diketahui, kita dapat menentukan rumus fungsi berdasarkan informasi yang diberikan.

Contoh:

Diketahui fungsi linear:
f(x) = ax + b

Jika f(1) = 5 dan f(2) = 8:

a + b = 5
2a + b = 8

Kurangkan:
a = 3

b = 2

Jadi:
f(x) = 3x + 2

7. Grafik Fungsi

Fungsi dapat digambarkan pada bidang koordinat. Nilai input biasanya diletakkan pada sumbu x dan nilai output pada sumbu y.

y = f(x)

Setiap pasangan (x, f(x)) dapat menjadi titik pada grafik.

Untuk:
f(x) = x + 1

x = 0 → y = 1
x = 1 → y = 2
x = 2 → y = 3

8. Fungsi Linear

Fungsi linear adalah fungsi yang memiliki bentuk umum:

f(x) = ax + b

dengan a dan b merupakan konstanta.

Contoh:

f(x) = 2x + 3

Gradien = 2
Konstanta = 3

Grafik fungsi linear berbentuk garis lurus.

9. Fungsi Kuadrat

Fungsi kuadrat mempunyai bentuk umum:

f(x) = ax² + bx + c

dengan a ≠ 0.

Contoh:

f(x) = x² - 4x + 3

a = 1
b = -4
c = 3

Grafik fungsi kuadrat berbentuk parabola.

10. Komposisi Fungsi

Komposisi fungsi adalah penggabungan dua fungsi atau lebih.

(f ∘ g)(x) = f(g(x))

Artinya kita menghitung g(x) terlebih dahulu, kemudian hasilnya dimasukkan ke fungsi f.

Contoh:

f(x) = x + 2
g(x) = 3x

(f ∘ g)(x)
= f(g(x))
= f(3x)
= 3x + 2

11. Fungsi Invers

Fungsi invers merupakan fungsi yang membalik hubungan dari suatu fungsi.

f⁻¹(x)

Jika:

f(x) = 2x + 4

Misalkan y = 2x + 4. Tukarkan x dan y:

x = 2y + 4

Kemudian selesaikan untuk y:

y = (x - 4) / 2

Jadi:

f⁻¹(x) = (x - 4) / 2

12. Syarat Fungsi Invers

Tidak semua fungsi mempunyai invers yang juga merupakan fungsi.

Salah satu konsep penting adalah fungsi harus bersifat satu-satu (injektif) agar inversnya dapat menjadi fungsi.

Tips: Untuk fungsi sederhana, cara mencari invers adalah menukar x dan y lalu menyelesaikan kembali terhadap y.

13. Contoh Soal

Soal:

Diketahui:
f(x) = 4x - 7

Tentukan f(5).

Penyelesaian:
f(5) = 4(5) - 7
= 20 - 7
= 13
Soal:

Diketahui:
f(x) = x² + 2x

Tentukan f(3).

f(3) = 3² + 2(3)
= 9 + 6
= 15

🧠 Latihan Cepat

Jika f(x) = 3x + 5, berapakah f(4)?

📚 Ringkasan Bab 6

  • Fungsi memasangkan setiap anggota domain dengan tepat satu anggota kodomain.
  • Domain adalah daerah asal.
  • Kodomain adalah daerah kawan.
  • Range adalah daerah hasil.
  • Notasi fungsi dapat ditulis f(x).
  • Fungsi linear berbentuk f(x) = ax + b.
  • Fungsi kuadrat berbentuk f(x) = ax² + bx + c.
  • Komposisi fungsi: (f ∘ g)(x) = f(g(x)).
  • Fungsi invers ditulis f⁻¹(x).
